## 📍 Overview

This project is a **cybersecurity web application** that hides secret messages inside images.

👉 First, the message is **encrypted using a password (AES encryption)**  
👉 Then, it is **hidden inside an image (steganography)**  

The final image looks normal, but it contains hidden data 🔐

## 🚀 Features

- 🔐 Hide secret messages inside images  
- 🔑 Password-based AES encryption  
- 🖼️ Image steganography (LSB technique)  
- 🔍 Decode message using correct password  
- ❌ Wrong password protection  
- 🌐 Full stack (Frontend + Backend)  
- ⚡ Live deployed project

## 🧠 How It Works

1. User uploads an image  
2. User enters message + password  
3. Message is encrypted (AES)  
4. Encrypted data is hidden in image  
5. Image is downloaded  

For decoding:
- Upload image + enter password  
- System extracts and decrypts message
